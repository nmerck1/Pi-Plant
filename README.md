# 🌱 Pi-Plant

This is a **full-stack plant monitoring system** that runs on my Raspberry Pi home server. 

**Tech Stack:**
- **Backend**: Go
- **Frontend**: React
- **Hosting**: Raspberry Pi 4
- **Database**: SQLite
- **Deployment**: Self-hosted on my raspberry pi home server
